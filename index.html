오늘의 ISS 고도 정보판

국제우주정거장(ISS)의 고도를 실제 공개 원천에서 조회하고, 하루 한 줄씩 기록해 어제와 비교합니다. 데이터가 오지 않으면 마지막 정상값을 지우지 않고 이유를 설명합니다.

실제 조회일별 기록수신 테스트확인 방법

① 지금 값 조회 전

—km

ISS가 지표면 위 몇 km 높이에서 도는지를 뜻합니다 (원천 필드 altitude, 단위 킬로미터). 약 400~430 km 사이에서 천천히 변합니다.

③ 수신 테스트 합성 시험값 · 실제 ISS 데이터 아님

공개 합성 fixture(단위 pt, 가상 날짜 2026-08-24/25)를 재생합니다. 실패 버튼은 매번 초기화 → D1-A(100) → D1-B(105) → 선택한 실패 순서로 실행합니다. 실제 기록과 섞이지 않습니다.

④ 짧은 확인 방법

  1. 위치 — 이 주소의 ① 지금 값, ② 일별 기록, ③ 수신 테스트.
  2. 행동 — ③에서 실패 버튼 하나 → “다시 시도 · 합성 복구” → ②의 “원자료” 열기.
  3. 통과 — 실패 시 105 pt 유지·“오래된 값”·원인별 다른 설명, 복구 시 120 pt·fresh/none·2건. ②는 서로 다른 KST 날짜 2건이고 원자료=저장값=화면값, 변화값이 재계산과 같음.
  4. 안 될 때 — ①에 실패 원인과 마지막 정상값(“오래된 값”)이 보이고, ②가 1건이면 “두 번째 실제 날짜 대기 중”이 보임.
